# История развития интернета
**Тема проекта:** История развития интернета
**CSS-фреймворк:** XP.css

**Live-сайт:** https://kuzennayaula.github.io/history-internet/
**Репозиторий:** https://github.com/kuzennayaula/history-internet

## Описание
Учебный проект по фронтенд-разработке: тематический сайт из 10 страниц,
посвящённый истории развития интернета от ARPANET до наших дней.
Вёрстка выполнена в стилистике Windows XP с использованием фреймворка XP.css.

## Технологии
- HTML5 (семантическая разметка)
- CSS3 (кастомные стили поверх XP.css)
- JavaScript (бургер-меню, табы, слайдер, валидация форм)
- XP.css — CSS-фреймворк

## Структура
- index.html — Главная
- prehistory.html — Предыстория
- www-birth.html — Рождение WWW
- browser-wars.html — Браузерные войны
- web2.html — Веб 2.0
- mobile.html — Мобильный интернет
- timeline.html — Хронология
- people.html — Персоны
- contacts.html — Контакты
- 404.html — Страница не найдена
